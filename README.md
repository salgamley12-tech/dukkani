# دكّاني — إدارة المحل

تطبيق ويب عربي لإدارة المبيعات والمخزون والزبائن والديون والمشتريات والمصروفات والتقارير. الواجهة تعمل دون تثبيت حزم أو خادم تطبيق، وتحفظ بياناتها في المتصفح على الجهاز الحالي.

## التشغيل الموصى به

**على Windows:**
1. نزّل المشروع عبر **Code → Download ZIP** ثم فك الضغط.
2. افتح مجلد المشروع في File Explorer، واكتب `cmd` في شريط العنوان ثم اضغط Enter.
3. نفّذ: `py -m http.server 8000`
4. افتح `http://localhost:8000` في Chrome أو Edge.

**على macOS أو Linux:** افتح Terminal داخل مجلد المشروع ونفّذ `python3 -m http.server 8000` ثم افتح `http://localhost:8000`.

إذا لم يكن Python مثبتًا، استخدم إضافة **Live Server** في VS Code، ثم اختر **Open with Live Server** على `index.html`.

## الوظائف

- لوحة ملخص للمبيعات والديون والأصناف منخفضة المخزون.
- إدارة المنتجات وأسعارها وكمياتها ووحداتها.
- تسجيل البيع مع تحديث المخزون، وإضافة الرصيد غير المدفوع إلى كشف حساب الزبون.
- تسجيل المشتريات لزيادة المخزون وتحديث تكلفة المنتج.
- دفتر زبائن يسجل الدين والدفعات الجزئية ومواعي�� التحصيل وسجل الحركات.
- تسجيل المصروفات، وعرض ملخصات وتقارير وتصدير سجل المبيعات CSV.
- تخصيص اسم المحل والعملة، وتصدير/استعادة نسخة احتياطية بصيغة JSON.
- واجهة عربية RTL متجاوبة مع الجوال والكمبيوتر.

## حفظ البيانات — اقرأ قبل الاستخدام الفعلي

البيانات محفوظة في `localStorage` للمتصفح على هذا الجهاز فقط. لا توجد مزامنة أو حسابات مستخدمين أو تخزين سحابي. لا تستخدم التصفح الخاص، ولا تمسح بيانات الموقع، واحفظ نسخة احتياطية بانتظام عبر **الإعدادات والنسخ الاحتياطي**. استعادة نسخة تستبدل البيانات الحالية. النسخة الحالية أداة تشغيل أولية وليست بديلًا عن نظام محاسبي معتمد أو قاعدة بيانات سحابية.

## نشر رابط عام

يمكن استضافة الملفات الثابتة على GitHub Pages من إعدادات المستودع، مع الانتباه إلى أن النشر لا يغيّر طريقة حفظ البيانات: لكل جهاز ومتصفح بياناته الخاصة.
