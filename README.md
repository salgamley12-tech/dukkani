# دكّاني — دفتر ديون الزبائن

واجهة عربية بسيطة لمتابعة ديون زبائن البقالة والدفعات ومواعيد التحصيل. هذه نسخة أولية تعمل مباشرة في المتصفح دون تثبيت خادم أو قاعدة بيانات.

## التشغيل

افتح `index.html` في متصفح حديث، أو انشر الملفات الثلاثة على استضافة صفحات ثابتة مثل GitHub Pages.

## الوظائف الحالية

- إضافة الزبائن مع رقم الهاتف والملاحظات.
- تسجيل دين جديد وتحديد موعد متابعة اختياري.
- تسجيل دفعات كاملة أو جزئية مع منع تجاوز الرصيد المستحق.
- كشف حساب زمني لكل زبون يوضح الديون والدفعات.
- ملخص إجمالي المستحقات والمتأخرات والدفعات الشهرية.
- البحث والتصفية والترتيب حسب الرصيد أو موعد المتابعة أو آخر حركة.
- تغيير رمز العملة وتنزيل نسخة احتياطية بصيغة JSON.
- تصميم متجاوب باللغة العربية واتجاه RTL.

## حفظ البيانات والخصوصية

تُحفظ البيانات محليًا في مساحة `localStorage` للمتصفح على الجهاز الحالي. لا تُرسل البيانات إلى خادم، ولا تتم مزامنتها بين الأجهزة. استخدم زر «نسخة احتياطية» بانتظام، ولا تمسح بيانات الموقع من المتصفح قبل حفظ نسخة. لمنع ضياع البيانات أو تمكين عدة مستخدمين من الوصول إليها، يلزم لاحقًا إضافة خادم وقاعدة بيانات وتسجيل دخول.

## ملاحظة

هذه نسخة أولية مخصصة لتجربة سير عمل الديون وليست نظام نقاط بيع أو برنامج محاسبة كاملًا؛ لا تشمل حاليًا إدارة المخزون أو الفواتير أو صلاحيات الموظفين.
